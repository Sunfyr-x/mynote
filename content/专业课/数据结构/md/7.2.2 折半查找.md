#折半查找

## 算法思想

二分查找，仅适用于有序的顺序表

## 折半查找的实现

```c

/**************************表结构定义**************************/
typedef struct{
	ElemType *elem;
	int TableLen
}SSTable;

/**************************查找算法**************************/
int Binary_Search(SSTable L, ELemType key){
	int low=0, high=L.TableLen-1, mid;
	while(low<=high){
		mid=high+low/2;
		if(L.elem[mid]==key){
			return mid;
		}
		else if(L.elem[mid<key]){
			low=mid+1;
		}
		else{
			high=mid-1;
		}
	}
	return -1;
}
```
