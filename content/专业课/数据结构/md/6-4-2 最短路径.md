## BFS算法

### 适用对象

- **无权图**的单源最短路径（或所有顶点对，逐点做 BFS）
- 图的连通性判断、层次遍历、拓扑排序（配合入度表）
- 求解"最少步数""最短转换"类问题

>单源最短路径：从一点出发，到其他各点的最短距离


### 算法思想

- **广度优先**：从源点出发，先访问所有距离为 1 的邻居，再访问距离为 2 的……
- 本质是**逐层扩散**，用队列维护"当前层"的顶点
- 无权图中，第一次到达某顶点时的路径即为最短路径（因为层数 = 距离）

### 算法步骤

```
1. 初始化：源点入队，标记 visited，distance[源点]=0
2. while 队列非空：
     出队顶点 u
     for u 的每个邻居 v：
         若 v 未 visited：
             标记 visited
             distance[v] = distance[u] + 1
             parent[v] = u
             入队 v
3. 重复至队列空
```

### 局限性

- **仅适用于无权图或边权全相等的图**（若边权不同，BFS 不能保证首次到达即最短）
- 对稀疏图效率尚可，但对稠密图 $O(V^2)$ 与 DFS 无异
- 无法处理负权边（不过无权图本身不涉及这个问题）
- 只能求单源最短路径，求全源需对每个顶点各跑一次 $O(V(V+E))$

## Dijkstra算法
https://www.bilibili.com/video/BV1uT4y1p7Jy/?spm_id_from=333.337.search-card.all.click&vd_source=c25181bdc454f7ad86c8e3737daac0e2
### 适用对象

- **非负权图**的单源最短路径
- 最短路、路由选择、GPS 导航等

### 算法思想

- **贪心 + 松弛**：每轮从"尚未确定最短距离"的顶点中选距离最小的，标记为已确定（该距离不可能再被缩短，因为所有边权 ≥ 0）
- 用该顶点松弛其所有邻居的距离
- 与 Prim 结构几乎一样，区别在于：Prim 维护的是**到 MST 的最小边权 key**，Dijkstra 维护的是**到源点的最短路径长 dist**

### 算法步骤

```
1. 初始化：dist[源点]=0，其余 dist=∞；所有顶点未 visited
2. 重复 V 轮：
     在 unvisited 中找 dist 最小的顶点 u
     标记 u 为 visited
     for u 的每个邻居 v：
         if dist[u] + w(u,v) < dist[v]：
             dist[v] = dist[u] + w(u,v)
             parent[v] = u
3. 结束，dist[] 即为源点到所有点的最短距离
```

### 局限性

- **不能处理负权边**：一旦有负权，已标记为"确定"的顶点距离可能被后续路径缩短，贪心选择失效
- 例：`A→B=3, A→C=5, C→B=-2`，Dijkstra 先确定 B 的 dist=3，但实际 A→C→B = 3 后更新为 3？不对，A→C=5, C→B=-2 → 3，相等；若 C→B=-3 则 A→C→B=2 < 3，但 B 已标记 visited 不再更新 → 错误
- 时间复杂度依赖实现：邻接矩阵 $O(V^2)$，堆优化 $O(ElogV)$

## Floyd算法

### 适用对象

- **全源最短路径**（任意两点之间）
- 允许**负权边**（但不能有负权回路，否则最短路径无定义）

### 算法思想

- **动态规划**：`dp[k][i][j]` = 只允许经过顶点 {1,2,…,k} 作为中转时，i 到 j 的最短距离
- 状态转移：`dp[k][i][j] = min(dp[k-1][i][j], dp[k-1][i][k] + dp[k-1][k][j])`
- 空间优化：滚动数组，直接用 `dist[i][j]` 原地更新

### 算法步骤

```
1. 初始化 dist 矩阵：dist[i][i]=0，有直接边则 dist[i][j]=w，否则 ∞
2. for k = 1 to V：              // 中转点
     for i = 1 to V：            // 起点
         for j = 1 to V：        // 终点
             if dist[i][k] + dist[k][j] < dist[i][j]：
                 dist[i][j] = dist[i][k] + dist[k][j]
3. 结束，dist[i][j] 即为 i→j 最短距离
```

### 局限性

- **时间复杂度 O(V3)**，顶点多时（>400）性能吃紧
- 不能处理**负权回路**：若有负环，最短路径可无限绕圈减小，Floyd 会给出错误结果（可通过检测 `dist[i][i] < 0` 判断是否存在负环）
- 空间 O(V2)，对超大规模图内存压力大
- 代码极简但"黑盒感"强，调试和路径还原需额外记录 `path[i][j]` 中转点

## 三算法速查对比

|维度|BFS|Dijkstra|Floyd|
|---|---|---|---|
|问题类型|单源（无权）|单源（非负权）|全源|
|核心结构|队列|优先队列/key数组|三重循环 DP|
|时间复杂度|O(V+E)|O(V2) 或 O(ElogV)|O(V3)|
|负权边|❌ 不适用|❌ 不能处理|✅ 可以（无负环）|
|负环|—|—|❌ 不行|
|路径还原|parent 数组|parent 数组|path 中转矩阵|
