## [[数据结构.pdf#page=192&selection=99,0,99,10|哈夫曼树和哈夫曼编码]]

树中所有叶结点的带权路径长度之和称为该树的**带权路径长度（WPL）**，记为
$$
WPL=\sum\limits^n_{i=1}w_il_i
$$
$$
加权平均长度 = WPL/各叶结点的权值之和
$$

在含有 n 个带权叶结点的二又树中，`WPL` 最小的二叉树称为哈夫曼树

用一个数组存储，数组下标是元素编号，存储的值是双亲下标

### [[数据结构.pdf#page=195&selection=160,2,160,10|并查集的基本实现]]

```c
/**************并查集结构定义**************/

#define SIZE 100
int UFSets[SIZE]

/**************并查集初始化**************/

void Initial(int S[]){
	for(int i = 0; i < SIZE; i++){
		S[i] = -1;
	}
}

/************并查集的Find操作************/

int Find(int x, int S[]){
	while(S[x]>=0)
		x=S[x];	
	return x;
}

/**********并查集的Union操作**********/

void Union(int S[], int Root1, int Root2){
	if(Root1==Root2) return;
	S[Root2]=Root1;
}
```

时间复杂度
`Find`:  $O(d)$
`Union`:  $O(1)$
`d`为时间复杂度

### [[数据结构.pdf#page=196&selection=63,2,63,10|并查集实现的优化]]

改进前：
- `Union`操作可能导致最后的集合树退化为一条链，深度达到n
- `Find`操作随着树的深度增大，消耗时间也增大
改进后：
- `Union`确保小树合并进入大树
- `Find`在找到根结点后，把所有集合里的点都挂载到根结点，方便后续查找

```c

/********************************Union********************************/
void Union(int S[], int Root1, int Root2){
	if(Root1 == Root2) return;
	if(S[Root2]<S[Root1]){
		S[Root1]+=S[Root2];
		S[Root2]=Root1;
	}
	else{
		S[Root2]+=S[Root1];
		S[Root1]=Root2;
	}
}

/********************************Find********************************/

int Find(int S[],int x){
	int root=x;
	while(S[root]>=0)
		root=S[root];
	while(x!=root){
		int t=S[x];
		S[x]=root;
		x=t;
	}
	return root;
}
	
```
