## 求关键路径

### 核心概念

|术语|含义|
|---|---|
|**事件**​|顶点，瞬间完成，无持续时间|
|**活动**​|边，有持续时间 w|
|**ve**​|事件最早发生时间（Earliest time）|
|**vl**​|事件最迟发生时间（Latest time），不影响总工期的前提下的最晚时间|
|**ee**​|活动最早开始时间 = 弧尾 ve|
|**el**​|活动最晚开始时间 = 弧头 vl - 活动持续时间|
|**关键活动**​|ee=el 的活动|
|**关键路径**​|由关键活动组成的从源点到汇点的路径（可能不止一条）|

> **关键路径 = 最长路径**（因为并行路径中，总工期取决于耗时最长的那条）

---

### 拓扑排序求点的最早开始时间（ve）

**思想**：按拓扑序从前向后递推，用边权做松弛。

**初始化**：源点 ve = 0，其余 ve = −∞（或 0，取决于约定）

```
for each vertex u (in topological order):
    for each edge (u, v) with weight w:
        if ve[u] + w > ve[v]:
            ve[v] = ve[u] + w
```

**原理**：事件 v 的最早发生时间 = 所有指向 v 的活动中，最晚完成的那个。

**手动计算口诀**：

> 从源点出发，沿每条路径累加时间，取**最大值**作为该事件的最早时间。

**例子**：

```
a/3
① ──────→ ②
│          │
│b/2       │c/4
│          │
③ ──────→ ④
    d/5
```

拓扑序：① → ② → ③ → ④

|顶点|ve 计算|结果|
|---|---|---|
|①|源点|ve[1] = 0|
|②|ve[1]+3 = 3|ve[2] = 3|
|③|ve[1]+2 = 2|ve[3] = 2|
|④|max(ve[2]+4=7, ve[3]+5=7)|ve[4] = 7|

→ 总工期 = ve[4] = **7**

---

### 逆拓扑排序求点的最晚开始时间（vl）

**思想**：按逆拓扑序从后向前递推，用边权反推。

**初始化**：汇点 vl = ve[汇点]（总工期），其余 vl = +∞

```
for each vertex u (in reverse topological order):
    for each edge (u, v) with weight w:
        if vl[v] - w < vl[u]:
            vl[u] = vl[v] - w
```

**原理**：事件 u 的最迟发生时间 = 所有从 u 出发的活动中，保证后续事件不延误的前提下，u 能拖到的最晚时间。

**手动计算口诀**：

> 从汇点倒推，沿反向路径减去时间，取**最小值**作为该事件的最迟时间。

**接上例**，vl[4] = ve[4] = 7：

|顶点|vl 计算|结果|
|---|---|---|
|④|汇点 = ve[4]|vl[4] = 7|
|②|vl[4] - 4 = 3|vl[2] = 3|
|③|vl[4] - 5 = 2|vl[3] = 2|
|①|min(vl[2]-3=0, vl[3]-2=0)|vl[1] = 0|

---

### 求关键活动与关键路径

|活动|ee（弧尾 ve）|el（弧头 vl - w）|ee = el?|
|---|---|---|---|
|a (①→②)|ve[1]=0|vl[2]-3 = 0|✅ 关键|
|b (①→③)|ve[1]=0|vl[3]-2 = 0|✅ 关键|
|c (②→④)|ve[2]=3|vl[4]-4 = 3|✅ 关键|
|d (③→④)|ve[3]=2|vl[4]-5 = 2|✅ 关键|

→ 所有活动都是关键活动！两条关键路径：

- ①→②→④（3+4=7）
- ①→③→④（2+5=7）

---

### 完整解题步骤总结

```
Step 1: 拓扑排序，得到拓扑序列
Step 2: 按拓扑序求 ve[]（正向松弛）
Step 3: vl[汇点] = ve[汇点]，按逆拓扑序求 vl[]（反向松弛）
Step 4: 对每条边 (u,v,w)，计算 ee = ve[u]，el = vl[v] - w
Step 5: ee == el 的活动为关键活动
Step 6: 关键活动连成的从源到汇的路径 = 关键路径
```

---

### 易错点 & 408 坑位

|易错点|正确做法|
|---|---|
|关键路径是最短路径|❌ 是**最长路径**​|
|ve 初始化为 0|❌ 只有源点为 0，其余应为 −∞|
|vl 初始化为 0|❌ 只有汇点 = ve[汇点]，其余应为 +∞|
|逆拓扑序手动推时方向搞反|记住：vl 是从后往前**减**时间|
|关键路径只有一条|❌ 可能有多条（并行的最长路径）|
|缩短非关键活动能缩短总工期|❌ 只有缩短关键路径上的活动才有效|
|缩短关键活动后关键路径可能改变|✅ 原来非关键的变成关键（需重新算）|

---

### 一句话

> **正向拓扑求 ve（取 max），逆向拓扑求 vl（取 min），ee=el 是关键活动，关键活动串起来是关键路径。**
