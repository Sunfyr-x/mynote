#二叉排序树

## 二叉排序树的定义

一个二叉树
左树的所有结点均小于根结点，右树的所有结点都大于根结点
递归定义

==进行中序遍历可以得到递增序列==

## 二叉排序树的查找

```c

//二叉排序树结点
typedef struct BSTNode{
	int key;
	struct BSTNode *lchild, *rchild;
}BSTNode, *BSTree;

//在二叉排序树中找值为key的结点
BSTNode *BST_Search(BSTree T, int key){
	while(T!=NULL && key!=T->key){
		if(key<T->key){
			T=T->lchild;
		}
		else T=T->rchild;
	}
	return T;
}

```

空间复杂度$O(1)$，不需要额外辅助空间
若是递归写法，则空间复杂度为$O(h)$，每一层递归占用一个栈帧

## 二叉排序树的插入

```c
//实现递归插入
int BST_Insert(BSTree &T, int k){
	if(T==NULL){
		T=(BSTree)malloc(sizeof(BSTNode));
		T->key=key;
		T->lchild=T->rchild=NULL;
		return 1;
	}
	else if(k==T->key){
		return 0;
	}
	else if(k<T->key){
		BST_Insert(T->lchild, k);
	}
	else{
		BST_Insert(T->rchild, k);
	}
}
```

`&`用于传递指针的引用，否则只是一个拷贝罢了

## 二叉排序树的构造

```c
//按照str[]的关键字顺序建立二叉排序树
void Create_BST(BSTree &T, int str[], int n){
	T=NULL;
	int i=0;
	while(i<n){
		BST_Insert(T, str[i]);
		i++;
	}
}
```

不同关键字序列可能得到`同款`或`不同款`二叉排序树

## 二叉排序树的删除

- 找到对应结点
- 是叶子就直接删
- 只有一棵子树，则把自己的孩子过继给自己的爸爸
- 若有两棵子树，则让自己的`直接前驱`或`直接后继`取代自己，因为这俩只有一个子树，方便处理
