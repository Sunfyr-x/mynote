## 有向无环图与表达式

### 表达式介绍

**有向无环图（DAG）在表达式中的核心应用 = 表达式的有向无环图表示（表达式 DAG）**，用来**消除公共子表达式**，压缩存储空间、避免重复计算。

#### 三种表达式形式回顾

|形式|运算符位置|例子（(a+b)×(a+b+c)）|
|---|---|---|
|中缀|操作数之间|`(a + b) * (a + b + c)`|
|前缀（波兰式）|操作数前|`* + a b + + a b c`|
|后缀（逆波兰式）|操作数后|`a b + a b c + *`|

#### 表达式树 vs 表达式 DAG

**表达式树**（二叉树）：每个内部节点是运算符，叶子是操作数。

```
*
       / \
      +   +
     / \ /|\
    a  b a b c
```

问题：公共子表达式 `(a+b)` 被**重复建了两棵子树**，冗余。

**表达式 DAG**（有向无环图）：共享公共子表达式，同一节点可被多个父节点引用。

```
*
       / \
      + ←─┘
     / \   \
    a   b   c
```

- 节点 `+` 只有一个，被 `*` 的两个子分支**共用**
- 节省空间，且每个子表达式只算一次

#### 表达式 DAG 的构造规则

1. 每个**运算符**对应一个内部节点，标注运算符
2. 每个**操作数**对应一个叶子节点
3. 若两个子树**结构完全相同**（运算符相同 + 操作数相同），**合并为同一个节点**
4. 边表示"运算结果的流向"（有向，从操作数指向运算符）

### 如何解题

#### 题型一：给定表达式，画出表达式 DAG

**步骤：**

1. 按运算符优先级拆分表达式
2. 自底向上构建（先算的在下层）
3. 遇到相同的子表达式 → 合并为同一节点
4. 标注方向（从叶子指向根）

**例题**：`(a+b) * (a+b) + c`

拆分：

- 左：`(a+b)`，右：`(a+b)` → 合并为一个 `+` 节点
- 然后 `*` → 一个 `*` 节点
- 然后 `+ c` → 顶层 `+` 节点

```
+
       / \
      *   c
     / \
    + ←─┘
   / \
  a   b
```

#### 题型二：给定 DAG/树，写出表达式

**步骤：**

1. 从叶子到根，按运算符的左右子树确定操作数顺序
2. 中缀需要加括号（按优先级）
3. 后缀/前缀直接按遍历规则

|遍历方式|对应表达式|
|---|---|
|后序遍历（左右根）|后缀表达式|
|先序遍历（根左右）|前缀表达式|
|中序遍历（左根右）|中缀表达式（需加括号）|

#### 题型三：表达式求值（栈方法，408 常考）

**后缀表达式求值（栈）：**

```
从左到右扫描：
- 遇操作数 → 入栈
- 遇运算符 → 弹出栈顶两个元素，运算结果入栈
扫描结束，栈顶即为结果
```

**中缀转后缀（栈）：**

```
从左到右扫描中缀表达式：
- 操作数 → 直接输出
- 运算符 → 与栈顶比较优先级：
    若栈顶优先级 ≥ 当前，弹出栈顶输出
    当前运算符入栈
- 左括号 → 入栈
- 右括号 → 弹出直到左括号
扫描结束，弹出栈中剩余运算符
```

**优先级表（408 常考）：**

|运算符|优先级|
|---|---|
|`!` `~` 单目|最高|
|`*` `/` `%`|高|
|`+` `-`|中|
|`<<` `>>`|中低|
|`<` `<=` `>` `>=`|低|
|`==` `!=`|更低|
|`&&`|低|
|`||

#### 题型四：判断表达式 DAG 的拓扑性质

- 表达式 DAG 一定是**有向无环图**（有环意味着循环定义，无意义）
- 可以进行**拓扑排序**（从叶子到根的方向）
- 拓扑序 = 计算顺序（先算叶子，再算内部节点）

---

### 一句话总结

> **表达式 DAG = 共享公共子表达式的有向无环图**，比表达式树省空间、避免重复计算。解题核心：识别公共子表达式 → 合并节点 → 按拓扑序自底向上计算。408 常考：画 DAG、DAG 转中缀/后缀、后缀求值、中缀转后缀。
