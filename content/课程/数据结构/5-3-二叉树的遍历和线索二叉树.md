## [[数据结构.pdf#page=152&selection=52,5,53,6|二叉树的遍历]]

### 先序/中序/后序

> [!PDF|] [[数据结构.pdf#page=152&selection=70,0,74,41|数据结构, p.152]]
> 根据二又树的递归定义，遍历一棵二又树的关键在于确定对根结点（N）、左子树（L）和右子树（R）的访问顺序。在遵循“先左后右”的原则下，常见的遍历方式有三种：先序遍历（NLR）、中序遍历（LNR）和后序遍历（LRN），其中“序”指的是根结点在遍历序列中的位置。

```c
// 先序遍历代码

void PreOrder(BiTree T) {
	if (T != NULL) {
		visit(T);
		PreOrder(T->lchild);
		PreOrder(T->rchild);
	}
}

// 中序遍历代码

void InOrder(BiTree T) {
	if (T != NULL) {
		InOrder(T->lchild);
		visit(T);
		InOrder(T->rchild);
	}
}

// 后序遍历代码

void PostOrder(BiTree T) {
	if (T != NULL) {
		PostOrder(T->lchild);
		visit(T);
		PostOrder(T->rchild);
	}
}

```
### [[数据结构.pdf#page=153&selection=120,2,120,6|层次遍历]]

[[数据结构.pdf#page=153&selection=124,9,124,31|从上到下、从左到右逐层访问二叉树中的各结点]]

> [!PDF|] [[数据结构.pdf#page=154&selection=8,0,10,30|数据结构, p.154]]
> 层次遍历需要借助一个队列，其基本思想如下：首先将根结点入队，随后不断出队并访问队头结点，同时将其存在的左右孩子依次加入队尾，直至队列为空

```c
// 层次遍历代码

void LevelOrder(BiTree T) {
	InitQueue(Q);//初始化辅助队列
	BiTree p;
	EnQueue(Q, T);//跟结点入队
	while (!IsEmpty(Q)) {//队列不空则循环
		DeQueue(Q, p);//队头结点出队
		visit(p);//访问出队结点
		if (p->lchild != NULL) EnQueue(Q, p->lchild);//左孩子入队
		if (p->rchild != NULL) EnQueue(Q, p->rchild);//右孩子入队
	}
}
```

>[!danger] 根结点判空？？？
>一般默认这棵树是非空的

### [[数据结构.pdf#page=154&selection=62,2,62,12|由遍历序列构造二叉树]]

> [!PDF|] [[数据结构.pdf#page=154&selection=66,0,70,30|数据结构, p.154]]
> 对于一棵给定的二叉树，其先序序列、中序序列、后序序列和层序序列都是唯一确定的。然而，仅凭这四种遍历序列中的任意一种，却无法唯一确定这棵二叉树。但若已知中序序列，并辅以其他三种遍历序列中的任意一种，则可以唯一地重构出该二叉树。

## [[数据结构.pdf#page=155&selection=120,0,120,5|线索二叉树]]

> [!PDF|] [[数据结构.pdf#page=155&selection=132,0,132,39|数据结构, p.155]]
> 遍历二叉树是按照特定规则将树中所有结点排列成一个线性序列，从而得到相应的遍历序列。在该序列中，除首尾结点外，每个结点都有唯一的直接前驱和直接后继。

> [!PDF|] [[数据结构.pdf#page=156&selection=14,4,14,27|数据结构, p.156]]
> 在含有n个结点的二又树中，共有n+1个空指针域

> [!PDF|] [[数据结构.pdf#page=156&selection=18,8,20,16|数据结构, p.156]]
> 可否利用这些空指针，直接指向结点在遍历序列中的前驱或后继？若能实现，便可像遍历链表一样高效地遍历二又树

>[!danger] 一个有效的线索二叉树在教材中严格基于三种遍历来定义，利用通过三种遍历的结构特征和空结点，使得可以通过任意结点访问其在遍历序列中的前驱和后继

```c
// 线索二叉树的存储结构
typedef struct ThreadNode{
	ElemType data;
	struct ThreadNode *lchild, *rchild;
	int ltag, rtag;//0代表孩子，1代表线索，左前驱，右后继
}ThreeNode, *ThreadTree;
```
